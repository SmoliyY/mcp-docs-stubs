# Specification Version 2025-11-25

The November 2025 release, coinciding with MCP's **first anniversary**, introduced async capabilities and enterprise-oriented features.

## Major Changes

### Tasks (Experimental)
New abstraction for tracking long-running server operations:
- Task lifecycle: created → running → completed/failed/cancelled
- Client can query task status and retrieve results
- Tasks persist for a server-defined duration
- Methods: `tasks/get`, `tasks/cancel`

### OpenID Connect Discovery
Servers can advertise auth configuration via OIDC Discovery:
- Standard `.well-known/openid-configuration` endpoint
- Simplifies client authentication setup
- Compatible with existing identity providers

### Icons Metadata
Tools, resources, and prompts can now include icons:
- Data URI format (inline SVGs, small PNGs)
- HTTPS URLs for larger icons
- Server info can also include an icon
- Improves host application UI

### Incremental Scope Consent
Servers can request additional permissions mid-session:
- No full re-authorization required
- User approves only the new scopes
- Better user experience for progressive permission requests

### URL Mode Elicitation
Elicitation now supports URL-type responses:
- Users can provide URLs as elicitation answers
- Useful for file uploads and link sharing

### Sampling Tool Calling
Sampling requests can now include tool definitions:
- Servers can provide tools when requesting LLM completions
- Enables more sophisticated agentic patterns

### OAuth Client ID Metadata
Support for OAuth Client ID metadata documents:
- Standardized client registration info
- Better client identity verification

## Security Enhancements

- **SEP-1024**: Client security requirements for local server installation
- **SEP-835**: Default scopes definition in authorization specification

## Status

This is the **latest stable** specification version as of its release date.
