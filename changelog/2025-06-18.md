# Specification Version 2025-06-18

The June 2025 release brought significant improvements to authentication, transport, and tool capabilities.

## Major Changes

### Streamable HTTP Transport
Replaced the HTTP+SSE transport with a simpler, more scalable **Streamable HTTP** transport:
- Single endpoint (`/mcp`) instead of two
- Optional session management via `Mcp-Session-Id` header
- POST for client messages, GET for server-initiated streams
- Better load balancing and proxy support

### HTTP+SSE Deprecation
The original HTTP+SSE transport was deprecated. Clients should migrate to Streamable HTTP.

### Structured Tool Output
Tools can now define an `outputSchema` and return structured data via `structuredContent`:
- Machine-readable results alongside text content
- Schema validation for tool outputs
- Better integration with typed systems

### OAuth Resource Server Classification
MCP servers are now officially classified as **OAuth Resource Servers**:
- Clear separation between authorization servers and resource servers
- Standard OAuth 2.0 patterns for token handling

### Resource Indicators (RFC 8707)
Added support for OAuth Resource Indicators to prevent token misuse:
- Tokens are bound to specific MCP server URLs
- Prevents confused deputy attacks
- Clients include `resource` parameter in auth requests

### Elicitation
New feature allowing servers to request information from users:
- Structured data collection via JSON Schema
- Multi-step interactive flows
- User can accept, decline, or cancel

### JSON-RPC Batching Removed
Removed support for batched JSON-RPC messages to simplify implementations.

## Migration Guide

1. Replace HTTP+SSE transport with Streamable HTTP
2. Update OAuth flows to include resource indicators
3. Consider adding structured output to tools
4. Remove any JSON-RPC batching usage
