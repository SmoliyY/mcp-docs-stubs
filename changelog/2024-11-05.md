# Specification Version 2024-11-05

This was the **initial release** of the Model Context Protocol specification, published alongside the public announcement by Anthropic.

## Core Features

### Protocol Foundation
- JSON-RPC 2.0 message format
- Client-server architecture
- Capability negotiation during initialization
- Session lifecycle management

### Primitives
- **Tools** — Model-controlled executable functions
- **Resources** — Application-controlled data sources
- **Prompts** — User-controlled template instructions

### Transports
- **stdio** — Standard input/output for local servers
- **HTTP+SSE** — Server-Sent Events for remote servers

### Additional Features
- Resource subscriptions
- Resource templates (URI templates)
- Logging support
- Pagination via cursors
- Progress notifications
- Sampling (server-initiated LLM requests)
- Roots for workspace context

## Initial SDK Support

- **TypeScript SDK** — `@modelcontextprotocol/sdk`
- **Python SDK** — `mcp` package with FastMCP

## Initial Server Implementations

- Filesystem server
- GitHub server
- Brave Search server
- SQLite server
- PostgreSQL server
- Puppeteer server
- Memory (knowledge graph) server
- Google Drive server
- Slack server

## Supported Hosts

At launch:
- Claude Desktop
- Claude Code
- Cursor IDE (early support)

## Notes

This version established the core protocol that all subsequent versions build upon. The fundamental architecture — hosts, clients, servers, and the three primitives — has remained stable through all revisions.
