# The MCP Ecosystem

The MCP ecosystem has grown rapidly since its launch, encompassing official SDKs, community servers, and host applications.

## Official SDKs

| Language | Package | Repository |
|----------|---------|------------|
| TypeScript | `@modelcontextprotocol/sdk` | `modelcontextprotocol/typescript-sdk` |
| Python | `mcp` | `modelcontextprotocol/python-sdk` |
| Java/Kotlin | `mcp-java-sdk` | `modelcontextprotocol/java-sdk` |
| C# | `ModelContextProtocol` | `modelcontextprotocol/csharp-sdk` |

## Popular MCP Servers

- **Filesystem** — Read/write local files
- **GitHub** — Repository management, issues, PRs
- **Slack** — Messaging and channel management
- **PostgreSQL** — Database querying
- **Brave Search** — Web search
- **Puppeteer** — Browser automation
- **Google Drive** — Document access
- **Memory** — Persistent knowledge graph

## Host Applications
